# 设计构想（Conception）

主要由用户完成（可能与 AI 头脑风暴），主要是探索思考、分析问题，澄清目标，以及为什么。主要是 **What** 和 **Why** 的逻辑。

不过如果必要，也可以包含具体的想法和细节，或者某些技术选择。

## 文件清单

|    功能    |    文件    |  简要说明  |
|------------|------------|------------|
| 发现与取回 | `Design.md` | 询问、探测、发布，以及如何核对路途、取回分片 |
| 本地存档 | `本地存储.md` | 家用目录、黑白名单，以及探测触发的补存 |
| 存储评估 | `存储策略.md` | 基于各种因素进行综合的补存评估，尽量周全 |


**维护规则：**

- 当用户或用户委托 Agent 完成一份构想文档时，更新上面的清单。
